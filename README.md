# esp32s3-multisensor-smartwatch
ESP32-S3 based multi-sensor smartwatch featuring PPG heart-rate and SpO2 monitoring, 9-axis IMU motion sensing, MEMS audio input, capacitive touch display, Wi-Fi and BLE connectivity, and USB-C charging, designed using KiCad 9.0.7.
## Hardware Features
- USB Type-C programming and charging
- UART test pads for debugging and firmware flashing
- Multi-voltage power architecture
- I2C, SPI, and I2S peripheral integration
